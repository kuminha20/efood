# efood UI

Projeto React baseado no layout em Figma: https://www.figma.com/file/JjduV2Tg713TzYUUsees8b/efood

Stack:

- Vite + React
- Styled Components
- React Router (v6)

Como rodar:

```bash
npm install
npm run dev
```

Páginas iniciais: `/` (Home) e `/menu` (Menu). Estilização via `styled-components` em `src/styles`.
